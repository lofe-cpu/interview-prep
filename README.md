# Interview Trainer

Тренажёр технических собеседований: изучаешь учебный материал по теме, решаешь
задачу, получаешь уточняющие вопросы «от интервьюера» и сверяешься с эталонным
ответом. Прогресс и стрик сохраняются автоматически.

## Возможности

- 🔐 Регистрация и вход (сессии через httpOnly-cookie, пароли хешируются scrypt)
- 🌓 Светлая и тёмная тема (переключатель в шапке, запоминается)
- 📖 Учебный материал с правильными подходами к каждой задаче
- 💬 Уточняющие вопросы от интервьюера по ходу решения
- ✍️ Ответ в формате «объяснение + код» с самопроверкой
- 📈 Прогресс по темам, история попыток, стрик (дни подряд)
- ➕ Задачи легко добавлять — просто дополни массив в `data/tasks.ts`

## Стек

- **Next.js 16** (App Router, Turbopack) + **React 19** + **TypeScript**
- **SQLite** через встроенный модуль `node:sqlite` — без отдельной БД и нативных зависимостей
- **Tailwind CSS 4** для стилей, **lucide-react** для иконок

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:3000

## Как добавить задачу

Открой `data/tasks.ts` и добавь объект в массив `TASKS`. Пример:

```ts
{
  id: "my-new-task",            // уникальный slug
  topic: "frontend",            // frontend | backend | algorithms | sql | system-design | ai
  title: "Название задачи",
  difficulty: "medium",         // easy | medium | hard
  sortOrder: 5,                 // порядок внутри темы
  description: "Условие задачи…",
  material: "Теория и правильные подходы к решению…",
  requirements: ["Что должен учитывать хороший ответ…"],
  clarifyingQuestions: ["Уточняющий вопрос интервьюера…"],
  modelAnswer: "Эталонное объяснение…",
  modelCode: "// эталонный код",
}
```

Перезапусти сервер — новая задача появится автоматически (существующие обновятся).

## Структура проекта

```
app/
  api/            # REST-эндпоинты (auth, attempts)
  login/          # вход
  register/       # регистрация
  practice/       # список тем и задач
  task/[id]/      # страница задачи (интервью)
  progress/       # статистика и история
  page.tsx        # главная (лендинг/дашборд)
components/       # React-компоненты
data/tasks.ts     # база задач (редактируется вручную)
data/topics.ts    # темы и их метаданные
lib/db.ts         # схема БД, сид, запросы
lib/auth.ts       # пароли, сессии
lib/meta.ts       # метки сложности/оценок
```

База данных хранится в `data/app.db` (создаётся автоматически, в git не попадает).
